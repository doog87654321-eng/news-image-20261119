## Run it
```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
This copies `entry.png` (1024×1024, under 1 MiB) to the output directory and checks it is a whole PNG within the size limits, so both runs write identical bytes. The image itself was rendered from `news.html` with a local headless Chromium (`node render.mjs`); all icons are original hand-drawn vector art, no photographs.
